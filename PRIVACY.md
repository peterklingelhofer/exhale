# Privacy Policy

We collect no data from the user whatsoever.

## Study builds

A build running under a lab's study file keeps a local session log so the participant can hand it
to the lab. The log records app start and stop, animation start and stop, each phase transition
with its scheduled and actual duration, reminder and auto-stop firings, the participant id and
condition code from the study file, the app version and the operating system name. It records
nothing about what else is on the screen, no keystrokes and no identity beyond the id the lab
assigned.

The log lives in the app's configuration folder and leaves the machine only when the participant
presses Export in Settings, which copies it to their Desktop (or to Documents, Downloads or the
home folder when there is no Desktop) for them to send. There is no network
code in exhale. Clear in Settings empties the log, and deleting the study file turns study mode off
at the next launch.
